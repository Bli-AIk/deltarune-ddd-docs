# 0001 · 曲库以「私有子模块」挂在 docs 下

- 状态：已定
- 日期：2026-09-27

## 背景

DDD 的设计稿要与 ZUN「秘封俱乐部」原曲对齐（分镜按小节踩点），所以 Obsidian 库里必须能直接播到曲目。

原做法是在 `deltarune-ddd-docs` 里放一个软链接 `music -> ../assets/audios/music`。该路径两边都不存在
（游戏仓库里真实存在的是**空的** `assets/music`），且 Obsidian 本就不遍历软链接目录——等于一直没工作。

难点：这些曲目是版权作品，**不能公开分发**；而 docs 是公开仓库，又是公开游戏仓库 `deltarune-ddd` 的子模块。
同时游戏仓库的 CI 用 `actions/checkout` + `submodules: recursive`（6 个 workflow、8 处），
`release.yml` 还会把整个检出（含子模块内容）打成公开 release 附件。

## 备选方案

1. **忽略的嵌套 clone**：`music/` 进 docs 的 `.gitignore`，本地 clone 一份私有仓库进去。零 CI 风险，
   但曲库在 docs 里没有声明，属"游离"状态。
2. **挂到 PrivateNotes 下**：PrivateNotes 是私有的，天然安全；但 `01-作品项目/DDD` 本身是 docs 的子模块，
   superproject 跟踪不到子模块内部路径。
3. **公开仓库直接放**：不可行，版权。
4. **去掉开关，把 CI 改成不递归**：`.gitmodules` 里正常声明 `music`，把 8 处 `submodules: recursive` 改成 `true`、
   `tools/start.sh` / `tools/build_android.sh` 去掉 `--recursive`。作者裸 `--recursive` 最顺，
   但把"报错"转嫁给了外部克隆者，且要动 6 个 workflow 文件。
5. **私有子模块 + `update = none`**：公开 `.gitmodules` 里声明 `music`，但标记默认不更新；作者本地覆盖为 `checkout`。

## 决定

采用 5。`music` 是 `deltarune-ddd-docs` 的子模块，指向私有仓库 `Bli-AIk/deltarune-ddd-music`；
公开 `.gitmodules` 中该条目带 `update = none`，作者的检出里用本地 `git config` 覆盖成 `checkout`。

**私有仓库的地址在公开 `.gitmodules` 里是明写的，这是有意的**：私有是为了"不散播有版权的音频"，
不是"藏仓库的存在"。名字泄露不侵犯任何人的权益，内容才是要害。

## 理由

- `update = none` 让所有递归路径（`git submodule update --init --recursive`、`actions/checkout` +
  `submodules: recursive`、`git clone --recurse-submodules`）**静默跳过**它。已实测：匿名递归克隆退出码 0，
  日志为「略过子模组 'docs/music'」；去掉该开关的负对照退出码 1。
- 曲库因此在 docs 里有正式声明，可版本化、可 `git submodule update` 更新，不是游离文件。
- 公开 release 打包时该目录根本不存在，**物理上不可能**把有版权的曲目带进发布物。

## 后果

- ✅ CI 与发布链零改动、零风险（8 处 `submodules: recursive` 一个字没动）。
- ✅ 外部匿名 `git clone --recurse-submodules` 实测退出码 0，不炸。
- ✅ 作者侧的不方便已抹掉：`deltarune-ddd/docs` 的本地 config 写了
  `submodule.music.update = checkout`，裸 `--recursive` 照常拉到；新机器/新 clone 用游戏仓库里的
  一条 `just music`。实测 `submodule update` 不会把 `music` 切成游离 HEAD（跑完仍在 `main`）。
- ⚠️ 公开发布物里永远没有音乐 ⇒ 将来写 BGM 加载**必须**先做存在性检查（`love.filesystem.getInfo`），
  缺失就静音 + 记日志。
- ⚠️ `PrivateNotes/01-作品项目/DDD` 那份检出**故意不覆盖**（保持 `none`），
  免得同一个 532 MiB 曲库在盘上出现第二份。
